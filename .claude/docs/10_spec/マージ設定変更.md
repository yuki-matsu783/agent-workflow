# マージ設定変更 仕様書

## 概要

- **背景・目的**: `.claude/docs/00_requirements/マージ設定変更.md` を参照。
- **スコープ**: `task-repo-merge-settings` スキルの対象設定・確認手順・スクリプト呼び出しの入出力と処理フローを定義する。

---

## 入力（Input）定義

### 入力元

- **入力元**: ユーザーの明示的な依頼のみ（他スキル・ワークフローからの自動委譲は入力元として扱わない）

### 入力データ

| 項目名 | 型 | 必須 | 説明 | デフォルト値 |
|--------|----|------|------|-------------|
| プラットフォーム | string | Y（自動判定） | `origin` のホスト名から判定 | - |
| 対象リポジトリ/プロジェクト | string | Y | `OWNER/REPO` または `GROUP/PROJECT` | 判定できたリポジトリ |
| 変更設定・値 | `--flag=value` | Y | 下記データ設計の対象設定表から選択 | - |
| 実行承認 | bool | Y | `AskUserQuestion` の回答 | - |

### 入力フォーマット

スクリプトへの `--flag=value` 形式の引数のみ。AIが自由なシェル文字列を組み立てることは許可しない。

---

## 出力（Output）定義

### 出力先

- **出力先**: GitHub/GitLabのリポジトリ/プロジェクト設定とユーザーへの報告

### 出力データ

| 項目名 | 型 | 説明 | デフォルト値 |
|--------|----|------|-------------|
| 変更前の値 | table | `--show` 実行結果 | - |
| 変更後の値 | table | 変更適用直後にスクリプトが自動表示 | - |

### ステータス（スキルの終了状態）

| 状態 | 意味 |
|------|------|
| 成功 | 変更後の値を報告 |
| 中断（承認なし） | 実行せず終了 |
| 中断（CLI未導入・未認証） | 案内して停止 |
| 失敗（権限不足・対象不明） | スクリプトの標準エラーをそのまま報告 |

---

## 処理フロー

### 基本フロー

1. `git remote get-url origin` でプラットフォームを判定する（判定不能・別対象指定時はユーザーに確認）
2. ユーザーの依頼から変更したい設定と値を確定する。曖昧なら `AskUserQuestion` で具体化する
3. 実行前にコマンドラインと変更内容（設定名・変更前後の値）を提示し、`AskUserQuestion` で実行可否を確認する
4. CLIの導入・認証を確認する
5. `--show` 付きでスクリプトを実行し、現在値を表示する
6. 手順2で合意した値のみを指定してスクリプトを実行し、変更する
7. スクリプトが自動表示する変更後の値をそのままユーザーへの報告に使う

### 例外フロー

1. 他ワークフローからの自動委譲・会話の流れのみでの呼び出し → 実行せず、ユーザーの明示的な指示を要求する
2. `gh`/`glab` 未導入 → `task-gh-install`（GitHub/GitLab両対応）を案内して停止
3. `gh auth status`/`glab auth status` が未認証 → 認証コマンドを案内して停止
4. リポジトリ/プロジェクトが見つからない・権限不足 → スクリプトの標準エラー出力をそのまま報告
5. 引数が不正・必須引数が無い → スクリプトがUsageを表示して終了

## データ設計

### 対象設定

| プラットフォーム | 設定 | 対応コマンド | 意味 |
|---|---|---|---|
| GitHub | Automatically delete head branches | `gh repo edit --delete-branch-on-merge` | PRマージ後にsource branchを自動削除 |
| GitHub | Allow squash/merge commit/rebase merge | `gh repo edit --allow-squash-merge` / `--allow-merge-commit` / `--allow-rebase-merge` | 使えるマージ方式を制限 |
| GitLab | Squash commits when MR is accepted | `glab api projects/:id -X PUT -f squash_option=...` | MR作成時のSquashの既定状態 |
| GitLab | Delete source branch when MR is accepted | `glab api projects/:id -X PUT -f remove_source_branch_after_merge=...` | MR作成時のDelete source branchの既定状態 |

### 既存スキルへの委譲内容

| 呼び出し元 | 用途 |
|-----------|------|
| `task-gh-install` | CLI未導入時の案内先 |

### 使用するghコマンド（同梱スクリプト経由）

```bash
bash .claude/skills/task-repo-merge-settings/scripts/github-merge-settings.sh --repo=OWNER/REPO --show
bash .claude/skills/task-repo-merge-settings/scripts/github-merge-settings.sh \
  --repo=OWNER/REPO --delete-branch-on-merge=true --allow-squash-merge=true \
  --allow-merge-commit=false --allow-rebase-merge=false

bash .claude/skills/task-repo-merge-settings/scripts/gitlab-merge-settings.sh --project=GROUP/PROJECT --show
bash .claude/skills/task-repo-merge-settings/scripts/gitlab-merge-settings.sh \
  --project=GROUP/PROJECT --squash-option=always --remove-source-branch-after-merge=true
```

## エラーハンドリング

### エラーコード一覧

| 状況 | 対処 |
|------|------|
| `gh`/`glab` 未導入 | `task-gh-install` を案内して停止 |
| 未認証 | 認証コマンドを案内して停止 |

| origin が GitHub/GitLab 以外 | 対象外として報告 |
