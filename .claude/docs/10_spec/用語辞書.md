## 概要

- **背景・目的**: `.claude/docs/00_requirements/用語辞書.md` を参照。
- **スコープ**:
  - 含む: 辞書ディレクトリの配置、ファイル構成、エントリの書式、既存の仕様書・要件定義書からの参照方法（リンクの張り方）

## エントリの書式

各エントリは以下の形式を基本とする。辞書自身を用語の正とはせず、**一言説明＋定義元（正典）へのリンク**に留める。

```markdown
### <用語名>

<一言説明>

- 定義元: `<正典ファイルへのパス>`（該当セクションがあればアンカー付きリンク）
```

正典を辞書側に複製しないことで、正典が更新されても辞書の記述が古いまま残るリスクを避ける。

## 既存文書からの参照方法（リンクの張り方）

仕様書・要件定義書の本文で、辞書に収録済みの用語を使う場合は、初出箇所に以下の形式でリンクを付ける。

```markdown
[<用語名>](../90_glossary/<ファイル名>.md#<アンカー>)
```

- リンク先のアンカーは、エントリの見出し（`### <用語名>`）から生成される GitHub 標準の slug（例: `### work-ticket-driven` → `#work-ticket-driven`）を使う
- 既存ファイルへの一括適用は本仕様のスコープ外。新規に文書を書く、または大きく改訂するタイミングで順次追加する
- 実演として `10_spec/スキル体系.md` にこの形式のリンクを追加済み（用語辞書の `スキル名.md` を参照）
