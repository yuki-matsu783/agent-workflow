# 用語辞書

プロジェクト固有の用語（スキル名・チケット type・主要なワークフロー用語）を一箇所に集約したディレクトリ。

## 目的

スキル名・チケット type・ワークフロー用語の定義が各仕様書・要件定義書に分散していると、リネームや用語変更のたびに更新漏れが起きやすい。本辞書は参照元を一本化し、「この用語について知りたければまずここを見る」という入口を提供する。

仕様の詳細（配置・ファイル構成・参照方法の正）は `.claude/docs/10_spec/用語辞書.md` を参照。

## ファイル一覧

| ファイル | 内容 |
|---|---|
| [スキル名.md](./スキル名.md) | `workflow-*` / `work-*` / `task-*` 各スキルの一覧 |
| [チケットtype.md](./チケットtype.md) | チケット駆動ワークフローの作業タイプ（`investigation` 等）の一覧 |
| [ワークフロー用語.md](./ワークフロー用語.md) | issue駆動・チケット・DoDなど主要なワークフロー用語 |

## エントリの書式

各エントリは一言説明＋定義元（正典）へのリンクの形式を取る。辞書自身が用語を再定義するのではなく、正典への案内役に徹する。

```markdown
### <用語名>

<一言説明>

- 定義元: `<正典ファイルへのパス>`
```

## 既存文書からの参照方法

仕様書・要件定義書で本辞書に収録済みの用語を使う場合は、初出箇所に以下の形式でリンクする。

```markdown
[<用語名>](../90_glossary/<ファイル名>.md#<アンカー>)
```

既存ファイルへの一括適用はスコープ外。新規作成・大きな改訂のタイミングで順次追加する。詳細は `.claude/docs/10_spec/用語辞書.md` を参照。
