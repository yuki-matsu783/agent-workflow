# アセット種類判定規約

ユーザーの要望を skill / rule / hook / agent のいずれに分類するかの判定規約です。

## 種類一覧

### skill

Claude Code が特定のユーザーの指示に応じて自動的に発火し、ワークフローを実行するアセット。

**判定基準:**
- ユーザーが具体的なタスクを「作って」「作成して」と依頼している
- 複数のステップからなるワークフローを含む
- メインの会話のコンテキストの中で実行される
- `description` にトリガーとなるユーザーの言葉を記載する
- `SKILL.md` に手順が記述される

**例:**
- "issue 作成するスキルを作って"
- "テストを実行するスキル"
- "ドキュメントを生成する指示"

### rule

継続的に適用されるルール・制約・規約。

**判定基準:**
- 特定の条件下で常に適用されるべき事項
- 違反検知や制約の定義が目的
- プロジェクト全体にわたって適用される
- `.claude/rules/` 以下に配置される

**例:**
- "コーディング規約を定義して"
- "コードレビューのチェックリスト"
- "セキュリティの制約ルール"

### hook

特定のイベント発火時に自動的に実行されるスクリプト。

**判定基準:**
- 特定のイベント（PreToolUse, PostToolUse, Stop など）に紐づく
- bash や sh で実装される
- `settings.json` の `hooks` セクションに登録される
- `.claude/hooks/` 以下に配置される

**例:**
- "Bash 実行前にファイルの権限をチェックする"
- "コミット前に lint を実行する"
- "ツール使用前に環境変数を検証する"

### agent

メインの会話から委任され、独立したコンテキストで特定の役割を担う subagent。

**判定基準:**
- 「○○担当」「○○専門」「○○役」のように役割・人格が定義されている
- メインの会話とは別のコンテキストで動き、結果だけを返せばよい
- ツールの制限、モデルの指定、並列実行、権限モードの分離が必要
- `.claude/agents/<name>.md` に frontmatter + system prompt の形式で配置される

**例:**
- "コードレビュー専門のエージェントを作って"
- "調査だけを任せる読み取り専用のサブエージェント"
- "テストを実行して結果を報告する agent"

**skill との使い分け:**

| 観点 | skill | agent |
|------|-------|-------|
| 実行コンテキスト | メインの会話と共有 | 独立（結果のみ返る） |
| ツール制限 | できない | `tools` で制限できる |
| モデル指定 | できない | `model` で指定できる |
| 並列実行 | 不向き | 複数同時に起動できる |
| 向いている用途 | 手順に沿ってユーザーと対話しながら進める作業 | 委任して結果だけ受け取りたい作業 |

詳細な frontmatter 仕様は `agent-rules.md` を参照。

## 曖昧な場合の判定フロー

```
ユーザーの要望を受け取る
    │
    ├─ イベント発火 + スクリプト実行か？
    │   ├─ はい → hook
    │   └─ いいえ → 次へ
    │
    ├─ 継続的・宣言的な制約・規約か？
    │   ├─ はい → rule
    │   └─ いいえ → 次へ
    │
    ├─ 独立した役割を持ち、委任して結果だけ受け取るものか？
    │   ├─ はい → agent
    │   └─ いいえ → 次へ
    │
    └─ タスク自動化のワークフローか？
        ├─ はい → skill
        └─ わからない → ユーザーに確認
```

## 名前付け規則

| 種類 | ファイル名の例 | ディレクトリ |
|------|---------------|-------------|
| skill | `<name>/SKILL.md` | `.claude/skills/<name>/` |
| rule | `<name>.md` | `.claude/rules/` |
| hook | `<name>.sh` | `.claude/hooks/` |
| agent | `<name>.md` | `.claude/agents/`（個人用は `~/.claude/agents/`） |

agent の `name` は小文字とハイフンのみ。frontmatter の `name` とファイル名を一致させる。
