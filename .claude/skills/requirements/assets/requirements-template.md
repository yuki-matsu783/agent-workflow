## ユーザーストーリー

**[As a]** <!-- ロール（誰が）--> 、

**[I want]** <!-- やりたいこと（何を）--> 、

**[So that]** <!-- 理由（なぜ）--> 。

### ユーザーストーリーの別パターン

必要に応じて、以下のパターンも使用できます。

| パターン | フォーマット | 例 |
|---------|------------|-----|
| 標準 | As a / I want / So that | As a 顧客として、I want 注文履歴を確認したい、So that 過去の購入内容を確認するため |
| 理由強調 | Now that / In order that | Now that 会員登録が完了したので、In order that すぐに購入を開始できるようにする |
| 条件付き | Unless | Unless ログインしていない場合、ページの内容は閲覧のみとする |
| 簡易型 | As a / I want | As a ゲストとして、I want 商品一覧を閲覧したい |

### 受け入れ基準の別パターン

| パターン | フォーマット | 例 |
|---------|------------|-----|
| 肯定（実行） | When / Shall | When ユーザーが「購入」ボタンを押したとき、Shall システムは決済を処理しなければならない |
| 否定（禁止） | When / Shall not | When ログインセッションが切れているとき、Shall not システムは個人情報を表示してはならない |
| 条件付 | If / Then | If カートが空である場合、Then システムは「カートが空です」のメッセージを表示しなければならない |
| 状態遷移 | When / Shall transition to | When 決済が完了したとき、Shall 注文ステータスを「確済済み」に遷移させなければならない |
