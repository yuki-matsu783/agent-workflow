# タスクログの記述規約

タスクログを一貫したスタイルで記述するための規約です。

## 命名規則

ファイル名は次の形式に従います：

```
<期間>-<件名>.md
```

例：`2026-08-29-ログイン機能実装.md`、`2026-08-31-週間レビュー.md`

## 日付フォーマット

- 日付: `YYYY-MM-DD` 形式
- 期間: `YYYY-MM-DD 〜 YYYY-MM-DD` 形式

## 記述の原則

### 達成事項

- 具体的な成果を記述する（「書いた」ではなく「実装した」）
- 成果の影響を添えると望ましい（「○○が改善された」など）
- 箇条書きで簡潔にまとめる

### 進行中の事項

- 現在の進捗率を必ず記述する（0〜100%）
- 次に取るべきアクションを明確にする
- 阻塞要因があれば明記する

### 障害・問題点

- 問題の影響範囲を記述する
- 対応策とその結果を必ずセットで記述する
- 類似の問題が再発しないための対策を含める

### 次回アクション

- 優先順位（高/中/低）を付与する
- 推定所要時間を添えると便利
- 依存関係がある場合は事前に記述する

## 用語の統一

| 用語 | 意味 |
|------|------|
| 達成事項 | その期間に完了したこと |
| 進行中の事項 | まだ完了していないが、作業中のこと |
| 障害 | ブロックとなった問題 |
| 次回アクション | 次に取り組むべきこと |

## テンプレートの選択

ワークスペースに応じて適切なテンプレートを選択する：

- **日次ログ**: 1日の活動をまとめたい場合
- **週間レビュー**: 1週間のまとめをしたい場合
- **プロジェクト進捗**: 特定プロジェクトの全体像をまとめたい場合
